# GenAI Learning Journal

My notes, experiments, and small projects as I learn Generative AI from scratch.

I'm working through Microsoft's [Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) course. Everything in this repo is written by me: what I understood, what confused me, and what I tried.

## How this repo is organized

- [`notes/`](./notes/): one file per day (`day-NN-name.md`), in my own words
- [`experiments/`](./experiments/): one folder per day (`day-NN-name/`) with the code I wrote for that day's exercise
- [`EXERCISES.md`](./EXERCISES.md): one exercise per day, taken from the course's assignments and challenges
